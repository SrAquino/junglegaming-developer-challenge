# Asset sources

The files under `public/assets/` were copied without conversion from the challenge-provided `assets/` directory at the repository root. They include ship sprites, tiles, effects, user-interface spritesheets, reference images and WAV audio.

The supplied directory does not contain a separate license file. These assets are used only as the visual basis requested by the Pirate Battle challenge. No third-party assets have been added.

The first playable scene currently loads `png/default/ships/ship_1.png` through PixiJS. Additional assets will use the same public asset root and will be documented here if converted or added.
